MyFather

Aviso de privacidad

Última actualización: 14 de septiembre de 2026.

Este aviso describe el tratamiento de información en MyFather. El contacto público para consultas y solicitudes es texthumanapp@gmail.com.

Información que se utiliza

Al crear una cuenta se utiliza tu correo, nombre de perfil, fecha de nacimiento, idioma y datos de autenticación. También se registra el progreso de aprendizaje, rachas, consumo de funciones de IA y estado de pedidos. Los perfiles infantiles son creados y gestionados desde la cuenta de una persona adulta.

Finalidades

La información permite iniciar sesión, recuperar el acceso, separar experiencias por edad, guardar progreso, entregar compras, responder solicitudes y proteger el servicio frente a abusos. No escribas datos sensibles innecesarios en nombres, actividades o reportes.

Preguntas e inteligencia artificial

La opción «Sin IA» utiliza respuestas preparadas. Si eliges una función de IA, el texto necesario y el contexto reciente se envían al proveedor de IA para generar la respuesta. No se guardan automáticamente nuevas conversaciones como historial permanente en la base de datos de MyFather. Un reporte que envíes expresamente sí se conserva para poder atenderlo.

Ubicación

La ubicación es opcional. El navegador solicita permiso cuando utilizas una búsqueda por ubicación. Puedes rechazarlo y buscar manualmente. Al abrir un enlace de mapas sales a un servicio externo sujeto a sus propias políticas.

Proveedores

MyFather utiliza Supabase para autenticación y datos, Cloudflare para funciones del servidor y seguridad, Mercado Pago para pagos y DeepSeek cuando eliges generación con IA. La infraestructura y estos proveedores pueden procesar información en otros países. MyFather no recibe el número completo de tu tarjeta ni su código de seguridad.

Menores

Las personas menores de edad deben utilizar la experiencia infantil bajo supervisión de una persona responsable. No deben incluir datos de contacto, ubicación precisa ni información privada en actividades. El modo infantil no envía preguntas a un proveedor de IA. La persona responsable puede solicitar la revisión o eliminación de la información del perfil.

Conservación y solicitudes

La información de cuenta y progreso se conserva para prestar el servicio. Los registros de operaciones pueden requerir conservación para resolver incidencias y cumplir obligaciones aplicables. Puedes solicitar acceso, corrección, eliminación o limitación del tratamiento al correo indicado. Evaluaremos la solicitud y las obligaciones de conservación que correspondan.

Almacenamiento del navegador

Se utiliza almacenamiento local para mantener la sesión y preferencias. Cerrar sesión elimina el acceso local a la cuenta. Las protecciones de seguridad reducen riesgos, pero ningún sistema garantiza que nunca ocurrirá un incidente.

Cambios

Publicaremos las actualizaciones de este aviso en esta página. Si una modificación requiere una decisión o autorización adicional, se solicitará antes del nuevo tratamiento.
